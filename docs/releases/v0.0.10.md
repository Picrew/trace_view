# Trace Review v0.0.10

## 全新应用图标(分层玻璃堆叠)

应用图标换成分层玻璃堆叠造型 —— 四层半透明圆角矩形叠在一起,顶层透亮、下方依次是紫与橙,呼应"一层层翻看 trace"这件事本身。Dock、启动台、Finder、DMG 以及浏览器标签页(favicon)现在统一是这个图标。

### 图标来源改为位图资产

此前图标是 `package-macos.sh` 里内联的一段 SVG,打包时经无头 Chrome 渲染成 PNG(`scripts/render-icon.ts`)。新图标是位图原画,所以:

- 新增 `assets/icon-1024.png` —— **唯一来源**,1024px 直通道(straight-alpha)透明 PNG,按 macOS 图标网格排布(1024 画布 / 824 内容区,四边各留 100px 边距)
- `assets/icon-source.png` 保留原始方图,配合 `scripts/extract-icon.py` 可完整复现抠图结果
- 打包流程不再依赖无头 Chrome,少一个外部依赖;`scripts/render-icon.ts` 随之删除
- iconset 目录每次打包前先 `rm -rf` —— 否则残留的旧尺寸位图可能把上一版图标混进 `.icns`

### 抠图实现要点

原画是渲染在一条**垂直黑→白渐变**背景上的方图,需要把主体从背景里精确抠出来。背景在每一行内是均匀的(实测横向漂移 ≤5 个色阶),所以逐行取左右两侧空白条的中位数即可得到精确的背景色 B,再把观测像素投影到 B→F 连线上求 alpha:

```
p = a*F + (1-a)*B   =>   a = ((p-B)·(F-B)) / |F-B|²
```

过程中踩到三个都会留下可见光晕的坑:

- **不能靠"与背景的距离"来判定不透明区**:原画边缘那一圈抗锯齿像素与背景的距离高达 89,远超任何还能兜住左下角近等亮度深紫层(距离仅 36.8)的阈值。单纯阈值化会把边缘像素按 alpha=1 连同它混过的颜色一起冻住,也就是沿轮廓留下 1px 灰边。改为:阈值只用来取**轮廓**,不透明内部由轮廓腐蚀 2px 几何地推出来
- **边缘带的 F 取最近内部像素的颜色**,这样反预乘能还原出边缘真实颜色,而不是把背景残留在里面(顶边贴黑会留暗晕,底边贴白会留亮晕)
- **`paste()` 不能传 mask**:以自身为 mask 粘贴等于把图合成到透明黑画布上,即预乘颜色,暗晕会原封不动地回来。直接 plain paste 才能保住直通道颜色
