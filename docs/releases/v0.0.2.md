# Trace Review v0.0.2

修复 v0.0.1 的两个体验问题 + 全新图标。

## 修复

### "一直在跳" — live 会话查看时的视口跳动(两个根因)

1. **浏览器 scroll anchoring 与虚拟滚动冲突**:内容更新时视口自发漂移(实测向上滚到中部后仍被拽动 244px)。修复:滚动容器禁用 `overflow-anchor`,漂移降到 66px 以内的测量残余。
2. **auto-follow 过于激进**:处于底部附近时每个 SSE batch 都把视口拽到底。修复:
   - SSE batch 前端合并节流(300ms),高频写入的会话(如正在运行的 agent)不再逐帧重渲染
   - follow 状态显式化 —— 向上滚动立即暂停跟随,出现 "↓ Follow live" 浮动按钮,由你决定何时恢复

### 图标重做

深色 squircle + 三条 timeline lane 之上的一条蓝→青→绿渐变上升轨迹,起点/中间/终点节点。替换 v0.0.1 的粗糙版本。

## 验证

- 33/33 单元 + UI 测试,真实浏览器 e2e 9/9(对打包产物)
- 跳动复测:修复前上滚后 244px 自发漂移 + 持续拽底 → 修复后 8 秒观察期零自发跳动
