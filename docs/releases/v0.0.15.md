# Trace Review v0.0.15

## 优化：搜索可见化第二回合——代码块、弹层、跨行

v0.0.14 把搜索命中画到了界面每一层，但真机会话审计后还有四个硌手的缺口，这一版补齐：

- **fenced 代码块高亮**：之前整块代码（``` 围栏）完全不高亮——而代码恰恰是 trace 里最常搜的内容。现在块内每一行命中都会下划线标出
- **链接不再被高亮截断**：之前命中落在 markdown 链接的 URL 里时，链接会被 `<mark>` 打断（href 截成半截）。现在链接整体走占位符保护：URL 完整可点，链接**文字**仍然高亮，行内代码也照常高亮
- **弹层不再常驻遮挡**：结果弹层在两处自动收起——结果返回时（看流里高亮比看列表重要）和 Enter 步进时。想再看候选列表按 **↓** 重新展开，再按 ↓ 步进
- **跨行匹配**：`fix the login` 现在能命中源文本里被换行断开的 `fix\nthe login`（空白折叠后再匹配，snippet 按规范化文本生成）
- **reasoning 命中窗口滑动**：命中藏在长 reasoning 的 200 字符预览之外时，预览窗口自动滑到命中位置（前后留 60 字符），高亮直接可见——之前只是展开但看不到 mark

**验证**：50/50 测试（新增：跨行命中、多空格查询、fenced 块 mark、链接 href 完整、链接文字高亮）。真实浏览器实测（claude-code 真实会话，7 个命中全在 reasoning 里）：命中定位 6/6 在视口内、结果返回即收弹层、↓ 重开列表、再 ↓ 步进（1/7 → 2/7）、reasoning 命中处流内 mark 数 0 → 2。
