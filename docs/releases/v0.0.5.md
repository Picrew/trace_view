# Trace Review v0.0.5

## 修复

### Dock 图标一直弹跳
app 是无窗口的后台服务,macOS 认为它"永远在启动中",Dock 图标不停弹跳。现在 `LSUIElement`(后台代理,无 Dock 图标)。**退出方式:网页界面右下角的 ⏻ Quit 按钮**。

### 图标白框
之前用 qlmanage 渲染 SVG,它把透明区域填成不透明白色 — 100px 的设计留白变成可见白框,图标显得比其他 app 大一圈。改用 headless Chrome 渲染真透明背景(四角 alpha=0 已逐像素验证),现在与系统 app 视觉尺寸一致。

### 其他
- 单实例:已运行时再次打开 app 只会打开浏览器,不再启动第二个实例
